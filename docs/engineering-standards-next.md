# Engineering Standards — Next Slices

1. **Citation-first retrieval** — implemented in this branch.
2. **OCR worker** — index scanned/image-only standards locally; keep raw PDF authoritative.
3. **Ranked chunk search** — return multiple relevant page/chunk hits with deterministic provenance.
4. **Authority profiles** — source-backed calculator assumptions with visible edition/page provenance and explicit project overrides.
5. **SirisHydro retrieval** — compose answers from retrieved evidence; Ollama explains but never replaces sources.
6. **Engineering knowledge expansion** — project notes, meeting notes, specifications, drawings and site photos under the broader SirisOS knowledge model.

The implementation order intentionally establishes evidence and provenance before generative answering.
