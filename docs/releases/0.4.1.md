# SirisOS 0.4.1 — SirisCore

SirisCore establishes the reusable platform services required by Mission Control and all future modules.

## Highlights

- Typed Event Bus and event-driven Mission Control refresh
- Module Registry and module-owned screens/actions
- Widget Registry and persistent layouts
- Deterministic Briefing Engine
- Explainable Siris Score and registered score widget
- Shared Scheduler
- Canonical AI Context Service
- Consolidated persisted SirisCore settings

## Deployment

```bash
git pull
make up
```

No database migration or manual configuration change is required.
