# SirisOS 7.61

- **Discarding a workout in SirisGym now stops the Apple Watch workout too.** It runs the same finish Shortcut that a finished workout runs, then comes back to SirisGym. Before, discarding left the Watch running. Discarding also stops the rest timer.
- **The finish Shortcut is told why it ran.** It gets `finished` or `discarded` as its input, so one Shortcut can end the Watch workout either way, and can do something different for each if you want.
- **Settings warns when nothing stops the Watch.** If a start Shortcut is set but no finish Shortcut, SirisGym → Settings says the Watch workout will keep running.

Set up: in SirisGym → Settings, name a finish Shortcut (e.g. "SirisGym Finish") and build it in the Shortcuts app so it ends the workout on your Watch. Which workout actions Shortcuts offers depends on your iOS and watchOS versions. Shortcuts only run on iPhone and iPad.
