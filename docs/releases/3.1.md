# SirisOS 3.1

- **Home changes through the day.** It leads with what matters now:
  - **Morning (5–10 am):** last night's top 3 and a button to today's brief. The Now section comes first.
  - **Work hours (weekdays 10–5):** your next meeting and your top 3, with shortcuts to Tasks and Engineering. The Today section comes first.
  - **Weekend:** the Home controls (protocols, cameras, car and power) come first.
  - **Evening and night:** a wrap-up prompt, or tomorrow's top 3 once you've wrapped up. The Home controls come first.
- **Your own order still holds:** within each section, widgets stay in the order you set in Customise Home. Only which section comes first changes.
- **You can turn it off** with the link under **Customise Home** ("Changes with the time of day · turn off"). The choice is per device.
- Whether you're home or away comes from SirisAI's presence check (SirisAI 2.14). It's shown on Home but not required: the time of day alone decides the order.

## Deployment

```bash
git pull
make up
```
