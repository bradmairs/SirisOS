# SirisOS 2.71

- **The brain is now called Siris:** "Second Brain" is gone from SirisOS. The Brain tab, its page, search results, the brief, the week view, quick capture, Career, iPhone shortcuts and `make verify` all call it **Siris**, matching the vault's own rename.
- **The assistant is SirisAI:** the assistant tab is now **SirisAI**, so there aren't two tabs called Siris. This also covers "Ask SirisAI", "Message SirisAI", SirisAI chats and SirisAI's memories in search and on the Siris page, and the home-screen shortcut. Chat replies saved to Siris are titled "SirisAI: …".
- The URLs (`/brain`, `/assistant`) and the API are unchanged, so bookmarks and shortcuts keep working.

## Deployment

```bash
git pull
make up
```

An "Ask Siris" shortcut you already added on the iPhone still works; only its suggested name changed.
