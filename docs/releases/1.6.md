# SirisOS 1.6

- **Works with patchy signal:** Home keeps the last data it loaded on your phone. Open SirisOS with no signal (on site, in the tunnel) and your widgets are there straight away, with a note saying "Offline · showing what it had at 7:42". When the connection's back it refreshes by itself. The same happens if the server can't be reached: "Can't reach SirisOS".
- **Opens offline:** the app itself is kept on the device too, so SirisOS launches from the Home Screen icon even with no connection.
- **Faster start:** with the last data on the device, Home shows your widgets the moment it opens and refreshes behind them, instead of showing loading cards first.
- Signing out wipes everything SirisOS kept on the device.

## Deployment

```bash
git pull
make up
```
