# SirisOS 1.4

- **Customise Home:** a "Customise Home" button under the widgets opens a sheet where you can move any widget up or down within Now, Today and Home, or hide it. Phone and desktop keep separate layouts, saved on the server so they follow you between browsers. Reset puts everything back. New widgets (a new app) show up in their natural place until you move them.

## Deployment

```bash
git pull
make up
```

The layout is stored in `data/app/home-layout.json`. No configuration change is needed.
