# SirisOS 7.5

- **Wrap up work at home time.** From 15 minutes before the end of the working day (4:30 pm, from Times of day), the Work page opens with a four-step wrap-up, and your phone gets one "Wrap up work" notification. The steps:
  1. What got done, sent to Siris as memories.
  2. Today's open work tasks, ticked to carry over to the next workday (Friday's go to Monday).
  3. The first thing for next workday, added as a work task.
  4. Anything worth logging as CPD.

  Saved in `work.json`. `/work?wrapup=1` opens it any time.
- **Chartership progress over time.** Application readiness is now recorded once a day (`chartership-history.json`, a year kept). A Chartership card on Work shows:
  - a ring for how ready the application is;
  - how many elements are solid;
  - the change over the last four weeks;
  - a 12-week trend;
  - the weakest elements and the next step.

  The career application API returns the same data as `progress`.
- **Ask about this page.** A sparkles button (in the top bar on phones, a pill at the bottom right on desktop) asks SirisAI about the page you're on. Pages that register a summary (Work and SirisGym, so far) send what's on them with the question, so "what should I focus on?" means here. The chat shows just your question.
- **Search everything covers more, with filters.** Tasks (open, and done in the last 90 days) and SirisGym (exercises with when you last did them and your best set, plus workout notes) are now searched. Filter chips narrow the results to one kind.
- **The weekly review notification has the week in a line**, for example "4 tasks done, 3 workouts, 6.5 h focused at work and 2 h CPD", counted from SirisOS's own data.
- **Visual check**: now covers Work (and its wrap-up) at an iPad width too (820 px), alongside phone and desktop. On desktop, work notes now share a row with the to-dos.

Settings: `SIRISOS_CHARTERSHIP_HISTORY_PATH` (optional; defaults to the data folder). No SirisAI change is needed.
