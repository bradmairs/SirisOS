# SirisOS 1.01

- **Sign-in**: a show/hide eye on the password field, so a mistyped password is easy to spot. The username and password boxes no longer autocorrect or spell-check, and a rejected sign-in now reminds you they're case-sensitive.
- **Forgot the password?** On the server, run `make reset-password`. It asks for a new password twice (nothing is echoed or printed), saves it to `.env`, keeps the old `.env` as a timestamped backup, and restarts SirisOS. Add `ARGS=--sign-out-all` to also end every signed-in session.

## Deployment

```bash
git pull
make up
```

No migration or configuration change is required.
