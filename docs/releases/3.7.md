# SirisOS 3.7

- **SirisOS backs itself up every night.** Everything SirisOS keeps that exists nowhere else goes into one file after 3am: tasks, journal and wrap-ups, weekly reviews, career and CPD records, Home layout, links, passkeys, shortcut keys, terminal 2FA and settings. 14 nightly backups are kept, plus the last 10 you make by hand.
- **A Backups card on System status:** when each backup ran and how big it is, **Back up now**, a download button, and **Restore**. Restore asks first, then puts every file in that backup back. What was there before is saved as a "Before a restore" backup, so you can undo a restore.
- **The Inbox tells you** when a backup fails or the newest one is over a day old.

## Deployment

Backups go to `./data/backups` by default. To keep them off the server, set `SIRISOS_BACKUP_PATH` in `.env` to a NAS mount, e.g. `/mnt/nas/sirisos-backups`. `SIRISOS_BACKUP_HOUR` moves the nightly run; `SIRISOS_BACKUP_STANDARDS=1` adds the large standards library.

```bash
git pull
make up
```
