# SirisOS 3.9

- **Access from here, on System status.** Tap **Check from here** at work, on mobile data or on the VPN. It tests SirisOS the way your phone sees it right then, and says in plain words what won't work and what to do:
  - which network you're coming in through (home, VPN or the internet) and how fast a request is
  - HTTPS, and how long the certificate has left
  - whether SirisOS is on the Home Screen. On iPhone, notifications need it.
  - whether it works with no signal
  - **Notifications:** it sends a real test and times how long it takes to arrive.
  - **Live updates:** whether a proxy or tunnel holds the Inbox's updates back.
  - **The terminal:** whether WebSockets get through, and whether each terminal host answers from the server.
