# SirisOS 4.0

- **Projects.** A new screen, in the menu, listing every project in Siris: what's due and when, how many tasks are open, and which have gone quiet. Finished projects are listed separately.
- **A page for each project** that brings everything about it together:
  - what the note says it is, with its linked notes
  - **open tasks:** the note's own, plus SirisOS tasks and SirisAI reminders that name the project. Tick them off here, or add one in plain words ("send levels friday").
  - **meetings** in the last fortnight and the next month that name it. Upcoming ones link to meeting prep.
  - **emails** from the last 90 days with its name in the subject
  - **Mark finished**, which takes its deadline and leftover tasks out of Siris' insights
- A short alias such as "WD" counts too, but only in capitals, so it isn't matched inside other words.
- Weekly review's quiet projects now open their project page.

## Deployment

Needs SirisAI 2.25 or later for the project list and the email search.
