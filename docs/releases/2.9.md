# SirisOS 2.9

- **Tasks** (in the menu, and a **Tasks** card on Home): one list of everything you have to do, grouped Overdue, Today, This week, Later and Someday. It brings together:
  - tasks you add in SirisOS;
  - every open `- [ ]` task in your Siris notes;
  - reminders you set by talking to SirisAI.
- **Add tasks in plain words:** "pay rego Friday", "call the plumber tomorrow at 9am", "log CPD every week", "stretch on weekdays", "renew passport 3/11". SirisOS reads the date, the time and any repeat.
- **Tick or snooze:**
  - Ticking a Siris task ticks it in its note. Ticking a SirisAI reminder cancels it.
  - A repeating task moves to its next date.
  - Snooze puts a task off to tomorrow, the weekend or next week. For notes and reminders the snooze is remembered in SirisOS, and the note or reminder itself isn't changed.
- **"Remind me to…" in quick capture** (and in the iPhone capture shortcut) adds a task instead of a note. A task with a time sends a phone notification when the time comes, through your Inbox notifications.
- **The brief and This week** show your SirisOS tasks too.

## Deployment

Needs SirisAI 2.14 or later and the Siris vault engine 1.41 or later, which add the vault task list and reminders. Without them, only SirisOS's own tasks show, and the page says so.

```bash
git pull
make up
```
