# SirisOS 11.2.2

- **Versions mean something now.** They're written **Section.Feature.Fix**:
  - **Whole number:** goes up only for a significant new section, like Health or SirisGym.
  - **Middle number:** goes up for a new feature or a bigger upgrade.
  - **Last number:** goes up for a fix or minor change.

  Each part counts on its own, so ten features in a row make 11.12.0, not 12.0.
- **The whole history was renumbered this way.**
  - **How:** every release since 1.0 was judged a section, a feature or a fix, and counted again in the order it shipped.
  - **The ten new sections:** Tasks 2.0.0, Smart home 3.0.0, Training 4.0.0, Health 5.0.0, SirisGym 6.0.0, Work 7.0.0, Life admin 8.0.0, Budget with things and people 9.0.0, Meals and trips 10.0.0, and Around the week 11.0.0.
  - **Where it ended up:** 10.61 became 11.2.1.
- **Where to find the old numbers.** Each release's notes say its old number, and [renumbering.md](../renumbering.md) lists them all. The GitHub tags and releases were recreated under the new numbers.

To update: `make update`.
