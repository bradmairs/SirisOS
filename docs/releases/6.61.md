# SirisOS 6.61

- **Today's health data is back.** The Apple Health setup (Training → Apple Health) said to set Health Auto Export's date range to "Previous 7 Days". That option sends the seven *full* days before today, so today never arrived: no sleep for last night, no steps, strain stayed at 0 and energy was only an estimate. The setup now says **Date Range: Default** (all of yesterday plus today so far), for both the health metrics and the workouts automations.
- Comes with SirisAI 4.04, which flags an export that stops at yesterday in the setup check, and reads sleep that arrives grouped by hour or as one segment per stage as one night.

Update: `make update` in SirisAI's `deploy` folder. Then in Health Auto Export, edit both automations and set Date Range to Default.
