# SirisOS 8.0

- **Receipts in email fill in Things.** A new Receipts in email card in Life admin finds what you've bought and adds it to Things, with the shop, date, price and warranty where the receipt gives them. It covers appliances, electronics, tools and furniture, not food or consumables. It checks each morning, or use **Check email** and **Look back a year**.
- **Nothing in your mailbox changes**, not even "read" flags. Each email is read once, so a thing you delete doesn't come back, and an order and its invoice add the item only once. Up to 25 emails are read per run, and the rest wait for the next one.
- **Connecting Gmail.** The card says when email isn't connected. Run `scripts/setup_gmail.sh` in SirisAI's folder on the server with a Gmail app password. Sending stays off, and morning draft replies stay off unless you've already set an hour for them.

Bills and subscriptions is unchanged: it looks ahead at what's due and skips receipts.

## Deployment

Needs SirisAI 5.21.

```bash
git pull && make up
```
