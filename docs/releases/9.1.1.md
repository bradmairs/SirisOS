# SirisOS 9.1.1

_Was 7.81 before the 2026-11-22 renumbering (a fix)._

- **Health → Data sync matches the new Health Auto Export settings.** The setup steps now say Time Grouping: Minutes for Health Metrics (Hours still works) and Time Grouping: Seconds, with heart-rate data on, for Workouts. SirisAI 4.3.1 makes the finer data count correctly: a sync split part-way through an hour adds up, the day you switched counts each hour once, and per-second workout heart rate is thinned to one point per 5 seconds so it stays small.
