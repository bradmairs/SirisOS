# SirisOS 11.14.0

**SirisGym: notes that do something, and a simpler workout screen.**

## Notes that do something

A note on a workout is read for four things, and each becomes a suggestion with **Do it** or **No**. Nothing changes without a tap.

- **Something sore** ("left shoulder twinged on the press"): spare that area next time, as a niggle, until you say it's healed.
- **Equipment taken or broken** ("squat rack was taken"): at this gym, swap that exercise for its closest alternative every time.
- **It felt easy** ("bench felt light"): go up a weight step on it next time.
- **Too heavy** ("couldn't finish the pulldowns"): come down a step next time.

A step up or down is used once, by the next workout with that exercise. That workout's plan says why: "Your note said it felt easy: +2.5 kg."

Where:

- **The Done screen** has a note box ("Anything to note?"). Its suggestions show as soon as you save it.
- A note written during the workout is read when you finish.
- **Today** shows any suggestions still waiting.

Simple rules read the note straight away, without a connection to the local AI. When the local AI is set up, it reads the note as well and catches phrasing the rules miss. It may only name exercises from that workout and the five areas (shoulder, elbow, wrist, lower back, knee); anything else it says is dropped. The "Imported" marker on old imported workouts is never read.

New: `PUT /api/v1/gym/sessions/{id}/note {note}` and `POST /api/v1/gym/note-actions/{id} {act: apply | dismiss}`. Finishing a workout and the overview both return `note_actions`.

## A simpler workout screen

RPE, set types (warm-up, drop, as many reps as possible, rest-pause) and "how it felt" are now behind **More** on the workout screen, next to All exercises and One at a time. Effort comes from the Watch's heart rate per lift anyway.

A set's number is just a number unless More is on. To keep them showing all the time, turn on **Always show RPE, set types and "how it felt"** in SirisGym's Settings (`show_extras`).
