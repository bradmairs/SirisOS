# SirisOS 1.2

Delete notes and memories from the Second Brain.

- **Delete a note:** every search result on the Brain screen, and every "Learned today" item, has a Delete button. A confirmation says how many notes link to it (those links are removed, and their words stay). The note leaves search, links and the mind map. Afterwards a bar offers **Undo**. Tick "Delete permanently" to remove it for good.
- **Recently deleted:** a new list under Brain → Manage. Each note there can be **restored** (back where it was, reconnected to the notes that linked to it) or deleted forever.
- **Siris's memories:** also under Manage, the memories Siris saved from your chats, searchable. Deleting one stops Siris recalling it; this can't be undone. The brain usually holds its own copy as a note, which you delete separately.
- Asking Siris to "delete the note about X" works too; it asks before deleting.

Needs SirisAI 1.1 and Siris Second Brain 1.1.

## Deployment

```bash
git pull
make up
```

No migration or configuration change is required.
