# SirisOS 8.91

- **The backup copy can't be the backup folder.** On the server, backups already went to the NAS (SIRISOS_BACKUP_PATH), and the 8.9 copy was pointed at the same folder: a copy onto itself, whose clean-up of "the newest 14" counted the real backups and removed the oldest nightly (30 October). The copy is now refused when its folder is the backup folder, and it only ever clears its own nightly copies. The copy setting is off on the server: the backups were already off it.
- The Backups card no longer says backups "stay on the server's disk" when there's no second copy; the folder it names may already be a NAS.
