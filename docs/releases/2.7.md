# SirisOS 2.7

- **Mark things done:** each item in Siris' "Coming up" has a **Done** button. On an overdue task it ticks the task off in its note (`- [x] … ✅ date`). On a project deadline it marks the project finished, which also stops its leftover tasks showing as overdue. The list refreshes straight away, and the week view and brief stop listing the item too.
- **Shorter lists:** every list on the Siris page with more than 3 items shows the first 3, with a **Show all** button to expand it and **Show fewer** to collapse it again. That covers Learned today, What the brain noticed, Coming up, Going quiet, Linked automatically, Could be linked, Topics, Memories and Recently deleted.

## Deployment

The Done button needs SirisAI 1.62 or later, and the Siris vault engine 1.3 or later (`brain.py done`).

```bash
git pull
make up
```
