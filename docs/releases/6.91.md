# SirisOS 6.91

- **Health says why today is empty.** When today has no steps or sleep yet, a note on Health → Today explains why, from the last export your phone sent:
  - it stopped at yesterday, so set Date Range to Default in Health Auto Export;
  - nothing has arrived for hours, because iPhone only lets it send while unlocked, so open the app and run the automation by hand;
  - or it arrived but had nothing for today yet.

  It links to Training → Apple Health, where every attempt is listed. The note goes away once today's data is in.
