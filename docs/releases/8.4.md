# SirisOS 8.4

- **Stop tracking things you removed on purpose.** System status has a new card, **What SirisAI watches**. It lists Docker's containers, stopped ones first, each with a switch.
  - **Switch one off** (for example Open WebUI, which you removed but which is still listed as exited) and SirisAI stops checking it, restarting it, offering updates for it and telling you it's down.
  - **Gone for good?** Containers you've switched off that are no longer in Docker at all are listed with **Watch again**.
  - **By chat:** you can also say "stop tracking open webui" to SirisAI, and the "is down" alerts now say how.

  Needs SirisAI 5.51.
