# SirisOS 11.13.0

**Splitting the budget by blocks.**

The budget's **Split between incomes** has a new way to split, **Blocks**, and it's now the default.

## Blocks

- **Expenses** is one block, **Spending** is one block, and **each savings type** (Travel, House, Emergency…) is its own block.
- Each block goes **whole to one income**. Of all the ways to hand them out, it picks the one closest to everyone paying the same share of their income.
- **Relocation is shared**: it's split between the incomes, weighted by income. Any savings block whose name starts with "Relocat" is shared this way unless you change it.
- **Who pays each block** lists the blocks with what each one costs and who pays it. Each block can be **Worked out** (the default), **Shared by income**, or given to one income. Changing one reworks the rest around it.
- Each income shows the blocks it pays, with a shared block's percentage.
- The kept split remembers these choices, and **Redo the split** keeps them.

By income, Equally and Whole lines are still there, with personal lines as before.

New: `blocks` in the split's choices, as `{block: "auto" | "shared" | an income's id}`. The block keys are `expenses`, `spending`, or a savings line's id.
