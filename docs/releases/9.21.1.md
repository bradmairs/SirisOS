# SirisOS 9.21.1

_Was 9.71 before the 2026-11-22 renumbering (a fix)._

- **Exercise pictures no longer cover the name in a workout.** The small picture was in a button sized for a 32 px icon, so the 44 px picture spilled over the start of the exercise name. It now has its own button the size of the picture, with a gap before the name.
- **Air Bike gets a bike.** The picture library's "Air Bike" is a crunch done lying on the floor, so the built-in Air Bike showed that. It now shows the stationary bike, and name matching never picks that misleading entry.
- The visual check now includes the workout's pictures, so this is caught before release.
