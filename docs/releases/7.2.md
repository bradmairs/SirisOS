# SirisOS 7.2

A Work dashboard for the working day, editing Siris from SirisOS, a fix for the security check, and Dom's iPhone counting as home.

## Work

- **A new Work screen** (/work, in the menu) for the engineering job, built to stay open from 8:00 to 4:30:
  - how long until home time, today's meetings, and the next one with a countdown and its location;
  - work tasks (overdue, today, this week) to tick off, and a box to add one as a work task;
  - to-dos in work notes in Siris (GVW and other Work/ notes), to tick off there;
  - work projects from Siris (under Work/, or named GVW or CMP) with what's due;
  - search work notes, and jot a note down tagged #work so the nightly sort files it under Work/;
  - the engineering project picked in Engineering, the calculators, and CPD hours against 150.
- **It switches in by itself.** Work hours now start at **8:00** (they were 8:30): a Times of day still on the old 8:30 start moves once; one you've set yourself stays. In work hours the phone tab bar's fifth button is **Work** (it was Career), and Home shows an **At work** card with the next meeting and what's due. Work can also be picked for either tab-bar button in Times of day.

## Siris

- **Edit notes**: open a note from a Siris search and tap **Edit**. Your text replaces the note's through the brain engine: its frontmatter is kept, mentions of other notes are linked, and the brain's history keeps the old text. If the note changed since you opened it (the nightly sort, another device), the edit is refused rather than overwriting it.
- **Edit memories**: on Siris → Manage, the pencil next to one of SirisAI's memories corrects its words.

## Security

- **Having a passkey no longer gets "add a passkey".** The check used to say the short admin password needs fixing "or add a passkey" even when you had one. Now, with a passkey, it says the password still signs in too, and offers **Passkey only** on the Security page: the password stops signing in and only your passkeys can. If every passkey is lost, `SIRISOS_PASSWORD_SIGNIN=on` lets the password back in.

## Smart home

- **Who counts as home**: a card on Smart home lists the phones that count as someone home, whether each is home now, and lets you add or remove one (with suggestions from the network). **Dom's iPhone** is added, so the away protocol is only suggested once both phones have left. Names are matched however UniFi spells them ("Dom's iPhone", "Doms-iPhone").

## Deployment

Needs SirisAI 4.49 and Siris engine 1.98.

```bash
git pull && make up
```

New settings: `SIRISOS_PASSWORD_SIGNIN` (on: the password can always sign in), `SIRISOS_SECURITY_PATH` (where Passkey only is kept, `security.json` in the data folder).
