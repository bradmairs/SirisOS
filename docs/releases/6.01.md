# SirisOS 6.01

**No more bare "Load failed" on Inbox buttons.**

- When an action such as **Update all** takes a while, SirisAI 3.72 answers after 20 seconds with "still working" and finishes in the background. The Inbox keeps the item and says "Still working on it; a notice will say how it went". The notice arrives when it's done.
- If the connection drops before any answer comes back, the Inbox says so in plain words ("Lost the connection before SirisOS answered…") instead of Safari's "Load failed".
- **System status → Setup** now flags a SirisAI older than 3.72 and says how to update it. On the server, run `make update` in SirisAI's deploy folder. `make up` on its own rebuilds the code that's already there, which is why "Update all" was still running the old way.

## Deployment

On the server, in SirisAI's `deploy` folder:

```bash
make update
```

It pulls both SirisAI and SirisOS, rebuilds and restarts them.
