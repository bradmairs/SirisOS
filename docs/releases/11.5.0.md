# SirisOS 11.5.0

**Siris link suggestions now end.** Needs SirisAI 4.26.0 and the Siris engine 3.02.

- **A weekly batch.** "Could be linked: this week" shows the week's batch, picked each Sunday: at most 10 pairs, at most 2 per note. It counts down ("3 of 8 left this week"). When the batch is done it says **All done for this week** and stays empty until next Sunday. It used to refill straight away with the next, slightly weaker pair.
- **A higher bar.** A pair is only suggested if it's 75% alike *and* has a second reason, shown under it: a shared tag, one note naming the other, or both linking to the same note.
- **Each pair asked about once.** **Link**, **Skip** (new: not now and not again) or **Not related**. A pair you leave alone for 4 weeks drops off by itself. Next week's batch only looks at notes that are new or have changed a lot.
- **Automatic links to look over.** Only links Siris made under 85% sure are shown. **Looks right** keeps one and takes it off the list; **Unlink** undoes it.
- **The auto-link threshold only goes up.** Your decisions can raise it above 80%, never lower it.
- **SirisAI's "Siris links to review" card** only counts what's left in this week's batch and the unsure automatic links, so it goes away when you're done.

New: `POST /api/v1/brain/skip-link`, `POST /api/v1/brain/looks-right`.

## Update

`make update` on the server: it updates SirisOS and SirisAI, and SirisAI pulls the Siris engine. The first batch is made the next time the Siris screen or the nightly tidy runs.
