# SirisOS 8.2

- **A receipt opens on the receipt itself.** When the email only says "invoice attached", you see the invoice PDF or photo, with **Open** beside it and the email tucked underneath. When the receipt is written in the email, you see the email. Pictures inside the email now show too. Receipts kept before this are redone the same way. Needs SirisAI 5.41.
- **New projects, and deleting them.** Projects has **New project**: a name, what it's about and an optional due date, saved as a project note in Siris. Each project has **Delete project**. Its note goes to Siris' deleted notes, and **Undo** brings it back.
- **The three SirisAI problems on System Status are fixed:**
  - SirisAI's real version is checked, not the name of its model (it said "ollama").
  - SirisAI's key into SirisOS is set on the server.
  - Updates are deployed by hand, so the self-updater warning no longer shows.
- **Section names are capitalised:** Smart Home, Wrap Up, Weekly Review, Your Year, Life Admin, Things & People, System Status.
- **Smart Home puts Home controls above the 3D model.**

## Deployment

Needs SirisAI 5.41.

```bash
git pull && make up
```
