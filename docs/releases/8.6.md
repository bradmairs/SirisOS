# SirisOS 8.6

Brad's SirisGym list:

- **Starting a workout stays in the Home Screen app.** The Watch Shortcut came back by a web link, which iOS opens in Safari, not the app. That left a second copy of SirisGym with no workout in it, so you started another, and another Watch workout. Now, from the Home Screen app, the workout opens first and the Shortcut runs with no link back. Return with **◀ SirisOS** at the top left. In Safari it still comes straight back. The finish and discard Shortcuts work the same way.
- **Weights no longer drop to one digit.** Retyping set 1's weight carried every keystroke down: deleting "100" took the sets below to 10, then 1, then they stopped following. Now the sets below follow once you've finished typing, from the weight it had before you started.
- **The rest timer doesn't disappear.** It's kept on the phone, so it survives iOS reloading the app (after the Shortcuts app, or a long lock).
- **Rest's over, with the app open.** iPhone doesn't show a push while you're in the app, so the end of a rest now chimes and shows a banner with the next set. It stays until you tap OK or tick the next set. Closed or locked, the push comes as before.
- **2 minutes' rest between exercises.** After an exercise's last set (a superset's, for one), the rest is **Rest between exercises** (Settings, 120 s by default) instead of the between-sets rest. After the last set of the workout there's none. Over a minute, the timer shows m:ss.
- **A rest you can see on the lock screen.** A web app can't make a Live Activity; only iPhone apps can. The Clock app's timer can, though. Name a Shortcut in Settings ("…and for each rest"), e.g. one that runs **Start Timer** with the input as seconds, and each rest starts a Clock timer on the lock screen and Dynamic Island. It opens Shortcuts for a moment each time, so it's off unless you name one.
- **Finish at the bottom too**, beside Discard.
- **Reorder exercises.** Use the up and down arrows during a workout and in the routine editor. A superset stays together: an exercise moved out of its group's run leaves the group.
- **Unmerge, and "Not the same".** Merged exercises are listed under **Merged** on the Exercises tab. **Unmerge** brings the exercise and its sets back, routines point at it again, and the pair isn't suggested again. **Not the same** on a suggested pair stops it being suggested. A copy of the file is kept before an unmerge.
- **A dropped connection doesn't lose a workout.**
  - The workout and its plan (suggestions, last time, rest) are kept on the phone, so you can keep logging. The plan used to be lost when iOS closed the app.
  - Finishing while SirisOS is down keeps the workout on the phone. That now includes a 502, 503 or 504 from the way in, which used to say "couldn't save" and, worse, could throw a waiting workout away. It retries every minute and whenever the app is opened.
  - If SirisAI is down when the workout reaches SirisOS, SirisOS tries again every five minutes, so it's still analysed against the Watch.
