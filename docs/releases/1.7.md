# SirisOS 1.7

- **Competency claim drafts:** in Career → Competencies, every Stage 2 element now has a **Draft claim** button. It builds a first draft from the evidence you've tagged with that element (newest first, with its links) and the structure Engineers Australia asks for: situation, what you did, the result, and how it shows the element. Elements with no evidence get ideas for what would count.
- **Write it up:** if a local Ollama model is set up (`OLLAMA_URL`, `SIRISOS_OLLAMA_CHAT_MODEL`), "Write it up" turns your evidence into first-person prose. It's told never to invent anything and leaves [placeholders] for what's missing, but check every claim.
- **Save to Second Brain:** saves the draft as "CPEng claim draft – E6 Identify, assess and manage risks" (and so on). Saving again adds to the same note.

## Deployment

```bash
git pull
make up
```
