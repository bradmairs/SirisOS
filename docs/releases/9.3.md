# SirisOS 9.3

SirisLearn learning paths on the home screen:

- **Learning paths in the Learning widget.** SirisLearn 1.4 adds learning paths (courses chained towards a goal, with an optional target date). The widget shows up to two unfinished paths with their percent, pace and next step; one that's behind or past its date shows as *Behind on <path>* and links to the next step.
- **Inbox nudge when a path is behind.** "Your learning path "<title>" is behind", once a week while it stays behind. Dismissing it lasts the week.
- Works with older SirisLearn versions too (no paths, nothing changes).
