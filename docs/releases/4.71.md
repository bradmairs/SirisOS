# SirisOS 4.71

**CPD: Engineers Australia's Excel export imports.**

- **The export opens.** Engineers Australia's "participant records" .xlsx has an empty colour in its styles. Excel ignores it, but the library SirisOS used to read it refused the whole file, so the import said it couldn't be read. SirisOS now reads the cells directly when that happens.
- **Its columns are understood:**
  - **Civil Engineering** (the column named after your area of practice) counts as area-of-practice hours.
  - The **Type I** to **Type VIII** hour columns are no longer mistaken for the activity's type.
  - **Total Hours** like "2h30m", the **Key Learnings**, and the title rows above the table and the total row below it were already handled.
- **Hours that count twice aren't double-counted.** Engineers Australia lets one activity's hours count toward more than one minimum: for example, a 2-hour meeting can be 2 h of area of practice and 1 h of business. The three-year total now adds up the activities' hours, not their categories, so overlapping hours count toward each minimum without inflating the 150-hour total.
