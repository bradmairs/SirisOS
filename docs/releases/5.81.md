# SirisOS 5.81

**Phone fixes: server rings, the dock and notifications.**

- **The Home server rings are the right size again.** 5.7's Health readiness ring reused the `ring` class name and stretched the CPU, Memory and Disk rings to the full width. The readiness ring now has its own `rring` class.
- **The dock stays at the bottom.** Nothing can widen the page sideways any more, and long words such as push-service URLs wrap inside their widget. On iOS, a sideways overflow or a closing keyboard left the dock floating mid-screen. The page also nudges itself back into place when the keyboard closes.
- **Notifications reach iPhones.** Apple refused SirisOS's push signature (403) because the default VAPID subject was `mailto:sirisos@localhost`. The default is now the project's page, and a localhost or `.local` `SIRISOS_VAPID_SUBJECT` is replaced with a warning in the log. A refused signature now shows a short message instead of the raw URL.

## Deployment

```bash
git pull && make up
```

If the test notification still fails after updating, turn notifications off and on again on the phone.
