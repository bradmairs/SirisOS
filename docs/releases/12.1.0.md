# SirisOS 12.1.0

**SirisTrails: walks named from where you went, and a better walk screen.**

## Names from the map

Apple Health keeps no name for a walk, so SirisTrails now names each one from OpenStreetMap:
- **Hikes:** the peak at the walk's high point ("Hanging Rock", "Mount Lofty"), else the named track you followed ("1000 Steps / Kokoda Track Memorial Walk", "Falls River Track"), else the park or reserve ("Sugarloaf Reservoir Park").
- **Walks:** the named track or park, else the suburb or town: "Kaiapoi loop" when it ends where it started, "Ivanhoe walk" when it doesn't.
- **Place line:** each walk also shows where it was, such as "Kaiapoi, Canterbury, New Zealand", in the list and on the walk. English names are used where OpenStreetMap has them.

Roads don't count as tracks, so a hike along a fire road gets the park's name instead. A walk you've renamed keeps your name. New walks are named within ten minutes, and the walks already there are named 40 at a time.

To find the names, a sample of each route's points goes to OpenStreetMap's public Overpass and Nominatim services, one request a second as they ask. If they're busy, the walk keeps its town name and is looked up again later. SIRISOS_TRAILS_PLACES=off turns this off.

## The walk screen

- **A proper title** with a rename button, and under it the kind (hike or walk, and loop), the place, and the date with start and finish times.
- **Stat tiles** that wrap cleanly on a phone: distance, time and moving time, average pace, ascent and descent, highest and lowest points, heart rate and energy. They no longer overlap.
- **The map:**
  - a darker edge under the route, so it stands out on satellite
  - kilometre markers
  - one Start-and-finish marker on a loop
- **The elevation profile:**
  - smoothed, so GPS wobble doesn't look like hills, and a flat walk looks flat
  - labelled heights and distances
  - touch or hover to see that point on the map
- **Splits:** each kilometre's time, pace and climb, with the fastest highlighted.
