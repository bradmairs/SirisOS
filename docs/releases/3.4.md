# SirisOS 3.4

- **Terminal shortcuts:** one-tap commands on the Terminal page. Tap one, enter a fresh 2FA code, and its output shows right there. Every run needs its own code, the same as opening a terminal, and each run is logged and sends a phone notification.
- **Three read-only shortcuts are built in:** **What's running** (Docker containers), **Disk space** and **Memory and load**.
- **Add your own** with **+ Add**, for example "Restart SirisAI": `cd ~/sirisai && docker compose restart`. You can tie a shortcut to one host.
- **Inside an open terminal**, your shortcuts appear above the keys. Tapping one types the command; you press Enter yourself.
- A shortcut stops after 60 seconds (`SIRISOS_TERMINAL_COMMAND_SECONDS`), and the last 64 KB of its output is shown.

## Deployment

```bash
git pull
make up
```
