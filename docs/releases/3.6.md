# SirisOS 3.6

- **iPhone home-screen widget:** your next event, the top task and how many things need you, without opening SirisOS. On **iPhone shortcuts** there's a ready-made script for the free Scriptable app: paste it in, then add a Scriptable widget. It needs a shortcut key with **Today**, which is read-only. Tapping the widget opens SirisOS.
- **A Fitness card on Home:** this week's kilometres (with a bar per day), runs, exercise minutes and average steps, from the iPhone Health shortcut. **Set a goal** adds a weekly kilometre target with a progress bar. The card only shows once there's health data.
- **Upkeep on System status:** when SirisAI's last backup ran and whether it's too old, whether a SirisAI update is waiting, SirisOS's version, and how long each app's HTTPS certificate has left. Anything under three weeks is flagged.

## Deployment

The widget, fitness card and backups need SirisAI 2.14 or later. For runs, add **Running distance** to your Health shortcut as `running_km`.

```bash
git pull
make up
```
