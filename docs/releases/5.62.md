# SirisOS 5.62

**Apple Health import: sturdier, and it says why it failed.**

Health Auto Export only ever reports "Export did not complete successfully", so SirisOS now keeps its own record.

- **What the phone sent lately**, on the Training page: each try, when, how big, and either what was saved or exactly why it failed. For example:
  - no Authorization header
  - the key doesn't match
  - not JSON
  - too big
  - SirisAI didn't answer
- **Any SirisAI version works.** SirisOS now reads Health Auto Export's format itself and passes SirisAI one day at a time, in the simple form SirisAI has always taken. It no longer needs SirisAI 3.11 for this.
- **An export with nothing SirisOS uses is fine.** It's accepted rather than failed, so "All Selected" doesn't trip it.
- **Up to 50 MB** per export (it was 10 MB), so a first export of everything goes through.

## Deployment

```bash
git pull && make up
```

Then in Health Auto Export, run the export again (or turn on Enabled and wait), and open Training → Apple Health to see what arrived.
