# SirisOS 8.41

- **Ask SirisAI about your workouts.** SirisAI can now read your SirisGym sessions, so you can ask it "what did I do at the gym on Monday", "show me my last leg day" or "what did I bench last week" and get every exercise and set back.
  - SirisAI's service key opens only the two read routes, the session list and one session. It still can't save, change or delete a workout.
  - When SirisAI asks for one session, SirisOS skips looking up its Watch workout (`?watch=false`), because SirisAI already has the heart rate.

  Needs SirisAI 5.73.
- The web checks run on Ubuntu 24.04 again: GitHub moved its default runner to 26.04, where the Playwright browser for the visual check can't be installed.
