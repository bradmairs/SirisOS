# SirisOS 9.51

- **No work at the weekend.** On Saturday and Sunday, work tasks stay out of Home (the Tasks card and the Today timeline), the iPhone widget, nudges and the evening wrap-up, and a work task with a time doesn't send its reminder. A task counts as work when you've set it to work, or when its words say so, which is the same rule Home already uses in work hours.
  - **The Tasks page** says how many work tasks are left for Monday, with **Show them** if you want them.
  - **The Sunday review** still lists next week's work, since that's what it's for.
  - **Your work tasks are untouched:** they come back on Monday.
