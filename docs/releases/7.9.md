# SirisOS 7.9

- **Protocols can be switched off, and their notifications too.** Each protocol in Smart home → Protocols has an on/off switch and a bell:
  - **Off**: it never runs, by hand or by itself. Away mode won't run or offer it, the "Run Away protocol" button and the intruder auto-lockdown skip it, and it drops off Home's Protocols card.
  - **Bell off**: nothing about it reaches your phone (an offer still shows in the inbox), and its own "Send a notification" steps are skipped.

  Switching doesn't make a built-in "your version". Needs SirisAI 5.11.
- **No more duplicate notifications.**
  - **Each phone counts once.** Each install of SirisOS now registers with an ID it keeps. When iOS renews a phone's notification subscription, the new one replaces the old one instead of adding a second "device", which used to deliver everything twice.
  - **See and remove extra devices.** Inbox → Notifications lists every device getting notifications, marks "this device", warns when the same phone appears twice, and lets you remove the old one.
- **One wind-down a night.** SirisAI's "Time to wind down" alert and SirisOS's "Time to start winding down" nudge both went to the phone. Now whichever comes first is the only one pushed. SirisAI's alert stays in the inbox either way.
- **The tab bar on phones is centred.** Its buttons size evenly now, so the icons sit at equal spacing and the middle one is at the centre of the screen. Before, a long label like "Smart home" pushed the row off-centre.
