# SirisOS 11.20.2

- **Standards search finds the best match across the whole library.** It used to stop once it had enough hits, in whatever order the standards were stored, and only then sort them. With 28 standards, a search like "critical storm duration" could return a wetland manual ahead of Australian Rainfall and Runoff. Now every standard is scored first (about a fifth of a second for 5,000 pages).
