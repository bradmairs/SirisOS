# SirisOS 1.31

- **GVW Timesheets, Helmarr, Neo Server and JEFIT removed from SirisOS:** their tiles are gone from the Siris App Suite, the sidebar, search and the app health counts, along with their `GVW_*`, `HELMARR_URL`, `JEFIT_URL` and `NEO_SERVER_URL` settings. The apps themselves are unchanged.

## Deployment

```bash
git pull
make up
```

Any `GVW_*`, `HELMARR_URL`, `JEFIT_URL` or `NEO_SERVER_URL` lines left in `.env` are now ignored and can be deleted.
