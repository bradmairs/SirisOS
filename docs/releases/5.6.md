# SirisOS 5.6

**A setup checklist on System status.**

System status now starts with **Setup**: every part of SirisOS that needs switching on, tested live each time you open it. Each one says whether it's **on**, **not set up** or **needs a look**, what it found, and how to fix it, with the exact setting names. The ones that need a look come first; the ones that are on are folded away.

It checks:
- **SirisAI:** connected, and new enough (3.11) for network alerts, power use and Apple Health.
- **Home Assistant:** controls and scenes.
- **UniFi:** the live network for the house and the alerts.
- **Power use:** the power sensors and meters, and whether the whole-house ones are named.
- **Apple Health:** whether data is arriving, and why not.
- **Phone notifications:** which devices get them, and whether they get the home alerts.
- **CPD from Engineers Australia.**
- **Nightly backups:** whether the newest is less than two days old.
- **SirisAI's key into SirisOS.**
- **The terminal:** its machines and two-factor.
- **The security settings.**
- **Each of the other Siris apps.**

Nothing here changes anything: it only looks.

## Deployment

```bash
git pull && make up
```
