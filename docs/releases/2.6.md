# SirisOS 2.6

- **Passkeys:** sign in with Face ID or Touch ID. Add a passkey on the new **Security** screen (sidebar → Security); the sign-in screen then offers **Sign in with a passkey**. The passkey stays on your devices (and syncs through iCloud Keychain); SirisOS keeps only its public half. Passkeys need SirisOS opened on a name (its Tailscale name, or a local domain), not a bare IP address: browsers don't allow them on IPs, and the screen says so.
- **Settings check:** the Security screen reviews this install and lists what to fix, worst first: a default or short sign-in secret (`SIRISOS_JWT_SECRET`), a default or short admin password, a too-short SirisAI service key, sessions that last too long, unchecked HTTPS certificates, and no passkey yet.
- **Wrong passwords are limited:** 8 wrong passwords (or failed passkeys) in 15 minutes from one device and sign-in waits until the 15 minutes are up.
- **Security headers:** every page and response now says no sniffing, same-origin referrers and framing only by SirisOS itself, and only SirisOS may use the camera and microphone.

## Deployment

```bash
git pull
make up
```

Then open Security and fix anything marked critical. In particular, if `SIRISOS_JWT_SECRET` is still the default, set it to the output of `openssl rand -hex 32` and restart (everyone signs in again).
