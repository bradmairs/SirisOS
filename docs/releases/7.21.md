# SirisOS 7.21

JEFIT imports are now exact: the right days, no duplicate sets, and only the exercises you did.

## SirisGym

- **JEFIT's export is read as JEFIT's export.** The file JEFIT emails has a table for everything: settings, routines, sessions, exercise logs, set logs, records. The importer used to read every table with a date and a name as workouts. So your **routines** (planned sets) were added as if done, on the day the routine was last changed, and sets were doubled. Friday's Shoulders had Barbell Curl, Skull Crushers, Hammer Curl, Triceps Extension and Dips added, and 6 sets each. Now only **exercise logs** become workouts.
- **The right day, in Melbourne time.** Each workout's day is JEFIT's own date for it. It's no longer the UTC timestamp, which put a 7 am Friday workout on Thursday and Thursday's on Wednesday. Start and finish times come from the JEFIT session, and each set's time from JEFIT's set log, so recent imported workouts can be lined up with the Watch.
- **No duplicates.** An exercise logged twice word for word on the same day is kept once.
- **The right exercises.** A match must use the equipment the name says, and not clash on position (seated isn't standing). Guesses need two thirds of the words in common. So "Machine Tricep Extension" is no longer the dumbbell Overhead Triceps Extension, "Cable Upright Row" isn't the barbell one, and "Cable Rope Hammer Curl" isn't the dumbbell Hammer Curl. Exercises with no true match become your own, named as in JEFIT, with their equipment. New exercises get their muscle from whole words, so "Machine" no longer reads as a chin-up.
- **Importing again fixes an older import.** Re-importing the export replaces every imported day. Imported days within the export's dates that JEFIT doesn't have (left by the old importer) are taken out, after a backup (`gym.before-jefit.<time>.json`), and exercises only they used are tidied away. Workouts logged in SirisGym itself are never touched. The preview says how many days will be replaced and taken out.

## To fix your data

Update, then in SirisGym → History → Import, upload the JEFIT export again and import it.

```bash
git pull && make up
```
