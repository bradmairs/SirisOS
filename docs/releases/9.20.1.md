# SirisOS 9.20.1

_Was 9.61 before the 2026-11-22 renumbering (a fix)._

- **Searching for an exercise mid-workout works again.** The workout screen updates every second for its clock and rest timer, and each update pulled focus back to the exercise picker itself, so the search box lost it and the iPhone keyboard closed before you could type. The sheet now takes focus once, when it opens, and leaves a field you're typing in alone. The same fix applies to every sheet in SirisOS.
