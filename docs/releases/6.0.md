# SirisOS 6.0

**Layout bugs caught before they ship, and notifications that say when they stop working.**

- **Visual checks in CI.** Every pull request now opens the main screens (Home, Brief, Health, Inbox, Tasks, Career, Training, Status, SirisAI, Wrap-up and Your year) at phone and desktop widths. It fails if a page scrolls sideways, anything sits past the edge of the screen, the dock isn't at the bottom, or a screen throws an error. The screenshots are kept with each CI run. Run it locally with `npm run build && npm run visual` in `apps/web`. The ring and dock bugs from 5.7 to 5.8 would have been caught by this.
- **Notification health.**
  - SirisOS records, for each device, when a notification last went out and the last error.
  - If a phone stops receiving (a changed key, iOS dropping the subscription), you get an Inbox alert and System status → Setup shows a problem.
  - Notifications on that phone show the reason.
  - A device nothing has reached for a week gets a low-key "notifications are working" check, so silence doesn't go unnoticed.
