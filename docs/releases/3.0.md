# SirisOS 3.0

- **Evening wrap-up** (**Wrap up** in the menu): two minutes at the end of the day, in four steps.
  1. **Today:** see what you got done, tick what's still open, or move the rest to tomorrow in one tap.
  2. **Today's meetings:** anything that looks like CPD shows its hours. **Log it** adds a task to record it in Engineers Australia tomorrow, which stays the only record. **Not CPD** stops it being suggested.
  3. **Tomorrow's top 3:** saved as tasks due tomorrow, and shown first in tomorrow's morning brief as **Your top 3**.
  4. **One line about today:** saved to Siris as a `journal` note.
- **A reminder at 5 pm:** a phone notification offers the wrap-up once a day, unless you've already done it. Change the time with `SIRISOS_WRAPUP_HOUR`.

## Deployment

```bash
git pull
make up
```
