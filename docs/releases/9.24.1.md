# SirisOS 9.24.1

_Was 10.01 before the 2026-11-22 renumbering (a fix)._

- **"Not right".** A 👎 under SirisAI's latest answer tells it the answer was wrong. SirisAI 4.19.0 records it and adds that request to the tests it runs every night, so the same mistake gets caught if it comes back.
- **Interrupt it.** Tap the orb while SirisAI is talking: it stops mid-sentence and starts listening straight away, instead of only going quiet.
- **"One moment, sir."** When a tool takes a while, SirisAI 4.19.0 says so out loud. You hear it, but it isn't written into the answer.
- **"Never mind".** Saying "stop", "never mind" or "that's all" ends the turn without an empty answer left behind.

Needs SirisAI 4.19.0 for "Not right", the "one moment" line and "never mind". Interrupting works with any SirisAI.
