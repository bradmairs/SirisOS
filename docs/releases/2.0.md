# SirisOS 2.0

(The version follows the usual rule: 1.9 plus a feature, +0.1.)

- **One-page PDF for saved calculations:** every saved calculation (Engineering → Calculators → Saved calculations, and those linked to a project) has a PDF button. It makes a one-page A4 sheet for the design file: the title, calculator, date and linked project; the method; every input with its unit; the results; your notes; the cited standard; and Prepared by / Checked by lines with dates. On iPhone it opens the share sheet (save to Files, OneDrive, Mail); elsewhere it opens in a new tab.

## Deployment

```bash
git pull
make up
```
