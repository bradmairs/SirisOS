# SirisOS 5.71

**The phone menu fits.**

On a phone, the side menu's glass panel stopped partway down once the list grew longer than the screen. Health and Training made it long enough to show, and the items below ran outside the panel. Now the panel always fills the height of the screen. The logo stays at the top and your name and sign-out at the bottom, and only the list in between scrolls.

## Deployment

```bash
git pull && make up
```
