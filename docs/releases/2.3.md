# SirisOS 2.3

- **What changed since yesterday:** the daily brief now opens with a **Since yesterday** card when something's different: warmer or cooler, new tasks and ones off the list, apps that went down or came back, more important email, the Second Brain inbox going up or down, and CPD hours added. (If the last brief was a few days ago, it says since which day.)
- **Past briefs:** every day's brief is kept for 60 days. On the Brief screen, the clock button lists them; open any to read it as it was that morning.

## Deployment

```bash
git pull
make up
```

Briefs are kept in `data/app/brief-history/`. The first "Since yesterday" appears the day after updating.
