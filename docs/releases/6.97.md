# SirisOS 6.97

- **SirisGym on the tab bar at gym time.** On a phone, from 6:00 to 7:59 am every day, SirisGym takes the tab bar's fifth place, so it's one tap away when you get to the gym. If you've picked your own fifth button in Times of day, it takes the fourth instead; if you've picked both, your picks stay. It goes by the phone's clock, and stays off when Home's "Changes with the time of day" is off.

## Deployment

```bash
git pull && make up
```
