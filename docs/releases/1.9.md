# SirisOS 1.9

- **CPD from your calendar:** Career → CPD has a **From your calendar** card listing events from the last and next 30 days that look like CPD: webinars, courses, conferences, workshops, IPWEA and AWA events, and so on. Each shows its date, hours (from the event's length; all-day events count as 7.5 hours a day) and a guessed category.
- **Log it in Engineers Australia in one go:** **Copy & open EA** copies the activity, date, hours and category, and opens Engineers Australia so you can paste it into Record my CPD. Then tap **Logged**. EA stays your only CPD record; the next import brings it into SirisOS. **Not CPD** hides an event for good. Events already in your EA import (same day, similar title) never show up.
- New `GET /api/v1/calendar?start=&end=`: every event between two dates, read from SirisAI. The coming week view uses it too.

## Deployment

Needs SirisAI 1.21 or later (its calendar range route). With an older SirisAI the card simply doesn't appear.

```bash
git pull
make up
```
