# SirisOS 11.6.1

**"Is this right?" asks about five notes a week, not forever.**

- The Home card used to ask SirisAI for its top 5 unchecked notes every time, so checking five just let the next five move up and the card never went away.
- Now five are picked each Sunday and kept for the week. The card counts down ("3 left this week").
- **Right**, **Fix it** and **Not now** all take a note off this week's card. A note you put off can come up in another week.
- A note checked somewhere else, such as in SirisAI's chat, leaves the card too.
- When the five are done, the card says thanks and is gone until next Sunday.

New: `POST /api/v1/brain/review/later`. The week's picks are kept in `review-week.json` (setting `SIRISOS_REVIEW_WEEK_PATH`).

## Update

`make update` on the server. The first batch is picked the first time Home opens after updating, so this Sunday brings one more set of five. After that, it's five each Sunday.
