# SirisOS 2.73

- **Where's Jug? in Links:** the Black Ops Zombies leaderboard at http://192.168.0.100:3045, with its jug icon. It goes into your games group if you have one (a name with "game", "gaming", "play", "fun" or "entertain"), or a new **Games** group if not.
- It's added once, the first time Links loads after the update. Delete it, rename it or move it and it stays the way you left it. It isn't added twice if you've already added it by hand.

## Deployment

```bash
git pull
make up
```
