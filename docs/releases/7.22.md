# SirisOS 7.22

Fixes for what System status and Access from here flagged.

## Live updates arrive in bursts

nginx keeps the `X-Accel-Buffering: no` header that SirisOS sends with its live streams (the Inbox, chat, the access check) for itself, so a proxy in front (Nginx Proxy Manager, doing HTTPS for sirisos.sirishome.org) never saw it. A front proxy that compresses responses then held the stream back and sent it all at the end. SirisOS's nginx now passes the header on, and streams also say `no-transform`, so updates arrive as they happen. Checked with a compressing nginx in front: before, two events 1.5 s apart arrived together; now 1.5 s apart.

## Certificate: "Not checked from here"

SirisOS's nginx replaced the "https" the front proxy reported with its own "http", so Access from here thought you weren't on HTTPS and skipped checking the certificate. It now keeps what the front proxy saw.

## Certificate · 192.168.0.100:8443 "runs out in 0 days"

That's SirisAI's Caddy, whose own certificates last 12 hours and renew themselves, so "0 days" was a false alarm. A certificate is now judged against its own lifetime: a short-lived one shows "Renews itself every 12 hours · 6 h left", and only warns if under a quarter of its life is left (it stopped renewing). Others still warn under 21 days.

## SirisAI updater

The note now says to run `make update` once in SirisAI's deploy folder: from SirisAI 4.5 that installs the updater too, and the updater checks for new releases with git, so the GitHub "404 Not Found" (SirisAI's repo is private) goes away without a token.

## Deployment

```bash
git pull && make up
```
