# SirisOS 9.0

SirisGym fixes, and last time's sets in every workout:

- **Scrolling a list no longer closes it.** Drag-down-to-close (8.5) acted on any downward drag in a sheet scrolled to its top. A list that scrolls inside the sheet (the exercise picker) is always at that top, so scrolling it down closed the sheet. Now only the tab at the top closes a sheet. It stays in view as the sheet scrolls, with a bigger touch area.
- **Search doesn't close the picker by mistake.** The picker shrank as a search narrowed the list, so a tap where the list had been landed on the page behind it and closed the sheet. The list keeps its height now. On any sheet, the page behind only closes it on a tap that starts and ends there, not a drag that started in the sheet (scrolling, selecting search text).
- **Last time, set by set, as in JEFIT.** Every exercise in a workout shows "Last time (day): 80×8, 80×8, 77.5×7" under its name. The Last column and the grey hints in empty weight and reps boxes are filled too. Before, these came only from a routine's plan, so an empty workout, an exercise added mid-workout or a swap showed "–". These come from the new `GET /api/v1/gym/last` and are kept on the phone for the gym's patchy signal. Editing a saved workout compares it with the one before.
