# SirisOS 4.92

- **Swipe for the menu.** On a phone or tablet, swipe in from the left edge of the screen to open the side menu: it follows your finger, then opens, or springs back if you let go early. Swipe it back to the left to close it. The ☰ button still works, and on wide screens the menu is always there.
- **Protocol steps get readable names.** A step you don't name is named from what it does when you save ("Turn on TV Lights", "Notify: Bins out"). Before, Home's Protocols card and the run preview showed the raw tool name. Steps made in chat are left exactly as they are.

git pull && make up
