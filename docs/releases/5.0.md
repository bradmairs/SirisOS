# SirisOS 5.0

**SirisAI keeps listening when it asks you something.**

- **Answer without tapping.** When SirisAI ends a spoken reply with a question ("Which room, the lounge or the office?"), the Assistant starts listening again by itself instead of showing "Tap to answer". Say your answer and it carries on in the same conversation.
- **Silence is fine.** If you say nothing for 8 seconds, it stops quietly and goes back to "Tap to talk". Nothing is sent.
- **Works on iPhone.** The microphone is set up on your first tap and kept, because iPhone mutes audio that starts without a tap.

Needs SirisAI 3.01 or later, which also decides more reliably when a reply is a question, makes waking a computer ask you first, and can wake any computer on your network by name.

## Deployment

```bash
git pull && make up
```
