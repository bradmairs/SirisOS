# SirisOS 2.4

- **iPhone shortcuts:** a new **iPhone shortcuts** screen (in the sidebar) for using Siris from Shortcuts and Siri.
  - **Open SirisOS where you want:** copyable links for Quick capture, Ask Siris, This week and Today's brief, to put on your Home Screen with an Open URLs shortcut.
  - **Shortcut keys:** Shortcuts can't sign in, so make a key and choose what it can do: capture to the Second Brain, ask Siris, read today's brief, run protocols. A key is shown once, stored only as a fingerprint, shows when it was last used, and can be revoked.
  - **Ready-made Shortcuts**, with your address and key filled in: "Hey Siri, capture" (dictate into the Second Brain), "Ask Siris" (spoken answer), "My day" (today's brief read aloud, with what changed since yesterday), and "Wind down" (runs the protocol).
- On Android and desktop, long-pressing the installed app's icon offers Capture, Ask, Week and Brief.

## Deployment

```bash
git pull
make up
```
