# SirisOS 2.2

- **Quick capture from anywhere:** a pen button in the phone's top bar (and **Quick capture** in the sidebar) opens a capture sheet on any screen. Type a thought or paste a link, add a **photo** straight from the camera, or record a **voice memo** (up to 4 minutes, transcribed into the note), then Save. It lands in your Second Brain's inbox and the nightly sort files it.
- Photos are shrunk to 2048 px on the phone before sending, then saved in the vault's `Attachments/` folder and shown in the note.
- `/capture` opens the sheet directly, ready for a Home Screen or Shortcuts link.

## Deployment

Photos need SirisAI 1.22 or later; voice memos need SirisAI's speech-to-text (`SIRISAI_STT_PROVIDER`) and the HTTPS address (for the microphone).

```bash
git pull
make up
```
