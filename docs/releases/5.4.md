# SirisOS 5.4

**Power use, in the house and on Your year.**

- **The house, lit by what it's drawing.** Turn on **Power** in the Smart home toolbar and each room glows green by how much its power sensors are pulling right now: brighter as it gets towards 2 kW. Jobs that need doing still glow orange over it.
- **A Power card** on the Smart home page shows:
  - what the house is drawing now
  - today's kWh
  - solar, if you have it
  - every power sensor in Home Assistant, busiest first

  Each sensor goes in a room by its name ("Dishwasher power" goes in the kitchen). Choose another room, or "No room", in the list.
- **Your year** has a **Power used** chart of kWh by month, starting from today. SirisOS samples every 10 minutes. It counts from:
  1. the house's own kWh meter, if SirisAI knows which one it is;
  2. otherwise every meter added together;
  3. otherwise the power sensors over time.

  A meter that's reset or replaced doesn't count negative.

## Deployment

```bash
git pull && make up
```

This needs **SirisAI 3.11** or later with Home Assistant. For the most accurate figures, set `SIRISAI_ENERGY_GRID_ENTITY_ID` (the whole house's power sensor) and `SIRISAI_ENERGY_METER_ENTITY_ID` (its kWh meter) in SirisAI. Set `SIRISOS_POWER_LOG=0` to stop the sampling.
