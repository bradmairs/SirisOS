# SirisOS 3.3

- **Email** (in the menu, and an **Edit the reply** link on drafted replies in the Inbox): the replies SirisAI drafted in its morning triage, one card each. Each card shows who it's from, the subject, the opening of their email, and SirisAI's draft, ready to edit.
- **Send** sends exactly what's in the box, edited or not, after asking first. **Later** puts a reply off for 3 hours and **Tomorrow** until 8 am; it comes back by itself. **I'll handle it** clears it.
- **Snoozing works in the Inbox too:** any snoozed item is hidden there until its time.

## Deployment

Sending an edited reply needs SirisAI 2.14 or later. Older versions ignore the edit and send SirisAI's own draft.

```bash
git pull
make up
```
