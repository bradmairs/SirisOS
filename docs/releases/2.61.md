# SirisOS 2.61

- **`make verify`:** one command on the server that checks SirisOS end to end against the live apps: every connected app, SirisAI's hub contract, calendar range and forecast, Second Brain search and insights, SirisAI's service key into SirisOS (allowed and refused routes), phone notifications, the security settings, and building today's brief. Each line is ✓ fine, ! worth a look, ✗ broken or · not set up; it exits 1 if anything's broken and changes nothing.
- `make verify EA=ea-export.csv` (the file copied into `data/app/`) tries a real Engineers Australia CPD export: how many activities, how many hours count, which categories had to be guessed. It's never imported.
- `make verify PUSH=1` sends every device that turned notifications on a test notification.

## Deployment

```bash
git pull
make up
make verify
```
