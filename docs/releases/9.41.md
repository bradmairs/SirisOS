# SirisOS 9.41

The code is public now, so nothing in it may let anyone in:

- **No published sign-in key.** If `SIRISOS_JWT_SECRET` was missing, short or still a placeholder, SirisOS fell back to a fixed development key, and with the code public anyone could have signed a session with it. Now it never uses one. Instead it makes its own random key, keeps it in the data folder (`jwt-secret`, readable by its owner only) and signs with that. The Security page still says to set your own.
- **No published password.** A missing `SIRISOS_ADMIN_PASSWORD`, or one left as `change-me` or `change-this-password`, no longer signs in, and doesn't open the Terminal. Passkeys still work, and `scripts/reset-password.sh` sets a real password.
- **CI only reads the repo** (`permissions: contents: read`).
- **`SECURITY.md`** says how to report a problem privately.

If your server was using a placeholder key (it shouldn't have been: the deploy's `setup.sh` makes a random one), everyone signs in again once. Terminal 2FA would need setting up again, because its secret is locked with that key.
