# SirisOS 7.8

SirisGym, ready for a first workout. I ran SirisGym as a new user would: drafted a programme, did Upper 1 twice, then checked history, progress and editing. These are the problems that run found.

- **A weight carries down to the sets below it.** On a first workout there's no last time to borrow from. Typing 60 on set 1 used to leave sets 2 and 3 empty, so ticking them saved them with no weight and the volume came out wrong (660 kg instead of 1,380 kg). Now a weight you type carries to the unticked sets after it that were empty or following it, as in Strong or JEFIT. Warm-ups and ticked sets keep their own weight. Ticking a set with an empty weight takes the set above's, then last time's.
- **Decimal weights type properly.** Typing 62.5 used to come out as 625 because the box dropped the "." as you typed it. The same fix applies to minutes and km for cardio, and to body measurements. A comma works as the decimal point too.
- **Edit a saved workout.** A workout's sheet in History has **Edit** next to Delete. It opens the workout to correct (weights, reps, sets, exercises, notes), and **Save** puts it back in place of the old one with its original times. It doesn't start or stop the Watch. **Stop editing** leaves the saved workout as it was.
- **A workout in progress shows on every page.** Leave the workout to check something else and a bar at the top of every page shows its name, minutes and sets, with **Carry on**. It's hidden on SirisGym's own page, which has its "In progress" card.
- The year's calendar now says "days trained" rather than "workouts" (two workouts on one day are one day).
