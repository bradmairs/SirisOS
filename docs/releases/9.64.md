# SirisOS 9.64

- **An empty workout comes back to SirisGym too.** Starting from a routine already returned you to the workout once the Watch's start Shortcut had run, but **Empty workout** (and Cardio) left you in Shortcuts.
  - **Why:** a routine's start loads its plan first, so the Shortcut opened a moment after the workout screen was up. An empty workout opened the Shortcut in the same instant as the screen change.
  - **Now:** every start (routine, empty, cardio, Repeat last, and the morning card) waits for the workout screen before opening the Shortcut, the same way a routine always did.
