# SirisOS 6.95

- **No duplicate workouts from a JEFIT import.**
  - A day you already logged in SirisGym isn't imported again. The preview lists those days, and the result says how many were left out.
  - The same set appearing twice in an export (overlapping files, or a repeated log line) counts once. Real sets of the same weight and reps are told apart by their set number and kept.
  - Importing the same export again still replaces those days instead of doubling them.
- **Exercises made from workout names are gone.** An earlier import read JEFIT's table of workout sessions as exercises. Each session's name ("Push Day" and so on) became an exercise of yours with empty sets. On first load after this update, SirisGym takes out empty sets, entries left with none, and your own exercises with no data anywhere that aren't in a routine. **No workouts are removed**, and a copy of gym.json is saved next to it first (`gym.before-cleanup.<time>.json`). The importer no longer reads a table without sets, or a row with no set in it.
- **Settings → Exercises with nothing logged** shows any such exercises and takes them out on demand.

Update: `make update` in SirisAI's `deploy` folder.
