# SirisOS 9.44

SirisGym: every exercise's helper muscles, and recovery that counts them.

- **Built-in exercises:** every compound lift now names the muscles that help it. Pec Deck, Lat Pulldown, the raises, curls, leg curls, lunges, planks, cardio machines and others gained helpers. True isolation lifts (pushdowns, leg extensions, calf raises, crunches) keep none. Traps count as back, obliques as abs.
- **Your own exercises** (most came from the JEFIT import) only ever got a main muscle, guessed from the name, and no helpers. When this update first runs, each gets the helpers its movement has: a row gets biceps and forearms, a squat glutes and hamstrings, a tricep press chest and shoulders. Exercises still on the "full body" fallback get their real main muscle too.
  - A main muscle you chose is kept, and so are helpers you set.
  - A copy of the file is kept first (`gym.before-muscles.*.json`).
  - The last week's workouts are sent to SirisAI again so its picture of your training follows.
- **New imports** get both muscles from the name.
- **New and Edit exercise** now show **Helped by**: tap the muscles that help. New fills both in from the name when you leave the name box.
- **Recovery counts helpers.** Before, only an exercise's main muscle counted, so your biceps looked fresh the day after rows. Two or more working sets as a helper now count, with half the recovery time. The card says "helping" when that's why a muscle is tired.
- **Fix suggestions agree.** The 8.7 suggestions for imported exercises now read the movement the same way as everything else.

Sets per muscle, muscle balance and the weekly set targets already counted a helper as half a set, so they follow with the new helpers.
