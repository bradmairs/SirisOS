# SirisOS 7.81

- **Health → Data sync matches the new Health Auto Export settings.** The setup steps now say Time Grouping: Minutes for Health Metrics (Hours still works) and Time Grouping: Seconds, with heart-rate data on, for Workouts. SirisAI 5.01 makes the finer data count correctly: a sync split part-way through an hour adds up, the day you switched counts each hour once, and per-second workout heart rate is thinned to one point per 5 seconds so it stays small.
