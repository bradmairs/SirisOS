# SirisOS 11.21.0

**Standards keep themselves up to date, and the MRWA library is in.**

## New versions, every week

- Each standard can record where it **downloads from**. Every Sunday morning (SIRISOS_STANDARDS_CHECK_HOUR, 4am) SirisOS checks each one:
  - **New address:** for publishers that put each version at a new address (IDM version 5.6 then 5.7, ARR V4.2 then V4.3), it reads their page and picks the newest link by version number.
  - **Same address, new file:** if the same link now serves a different document, that's a new version.
- **A new version replaces the old automatically.** It's stored as a new revision, exactly like **Upload new revision**: the old one is kept as superseded, and you get a notification.
- **No false alarms.** A PDF re-generated with the same text (new timestamps only) isn't counted as a new version.
- Engineering → Standards shows when the library was last checked, what changed, and anything that couldn't be checked, with **Check now**.
- **Edit details** has the download address, plus the page and link pattern for publishers that move each version to a new address.
- Only the addresses set on your standards are ever downloaded from. Anything that isn't a PDF, or is over the upload limit, is refused.

## MRWA

The free Melbourne Retail Water Agencies standards and guidelines are in the library, each with its download address so new versions are picked up:
- **Water:** standard drawings 100–500 series, the standards index and cathodic protection drawings.
- **Sewer:** standard drawings 100–500 series, the overview parts and the MHTA-07 appendix.
- **Pressure sewer:** the supplement standard drawings.
- **Trade waste:** the 14 drawings.
- **Specifications and guidelines:** backfill specifications, water quality compliance, survey manual, build over guidelines, water metering and servicing guidelines, the pressure sewerage supplement, and South East Water's sewage pumping station supplement.

The MRWA editions of the WSAA codes (WSA 02 and WSA 03) aren't free: they're bought from WSAA. CAD, ZIP and Word files aren't added; the library is PDFs.

New: `source` on standards; `GET /api/v1/engineering/standards/updates`, `POST /api/v1/engineering/standards/updates/check`; `source_url`, `source_page` and `source_pattern` on `PATCH /api/v1/engineering/standards/{id}`.
