# SirisOS 12.0.1

- **Large Apple Health exports upload to SirisTrails.** SirisOS's web server capped uploads at 110 MB, so a 300 MB export.zip failed with "Request Entity Too Large". The export upload now takes up to 8 GB, streamed straight through, with longer timeouts for a phone on mobile data. Other uploads keep the 110 MB limit.
