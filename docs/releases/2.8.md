# SirisOS 2.8

- **Terminal:** a shell on a machine at home, from SirisOS (**Terminal** in the menu). Use it from work over Tailscale or your VPN. It works on the phone too, with Esc, Tab, Ctrl and arrow keys above the keyboard.
- **2FA every time:** each terminal needs a fresh code from an authenticator app: the iPhone's Passwords app, Google Authenticator or 1Password.
  - Setting 2FA up needs your SirisOS password, so a stolen sign-in can't set it up or use it.
  - Each code works once.
  - Five wrong codes lock unlocking for 15 minutes.
- **SSH under the hood:** SirisOS connects with its own SSH key, and only to the hosts you list. It remembers each host's key and refuses to connect if that key changes.
- **Sessions close by themselves** after 15 minutes with no typing, or 2 hours in all.
- **You can see what happened:** every unlock, wrong code and session is listed on the Terminal page. Your phone gets a notification whenever a terminal opens. Keystrokes are never recorded.
- The Security page's settings check now covers the terminal.

## Setting it up

1. On the server, add the host to SirisOS's `.env`, for example `SIRISOS_TERMINAL_HOSTS=home=brad@192.168.0.100`. Then run `git pull && make up`.
2. Run `make terminal-key`, and add the line it prints to `~/.ssh/authorized_keys` for that user on the host.
3. Open **Terminal** in SirisOS, enter your password, scan the QR code with your authenticator app (or tap the link on the iPhone), and enter the first code.
4. From then on: open Terminal, enter a code, and you're in.

Lost your phone? Run `make terminal-reset-2fa` on the server and set it up again. Reinstalled a host? Run `make terminal-forget-host NAME=home`. See [ADR 113](../adr/113-terminal.md) for how it's secured.
