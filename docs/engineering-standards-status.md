# Engineering Standards Status

## Implemented
- Private authenticated PDF upload and persistent local storage.
- Metadata for authority, reference and edition.
- Page-level local text extraction.
- Deterministic ranked multi-page keyword search.
- Search hits with snippets, scores and page citations.
- Authenticated exact-page retrieval for downstream AI context.
- UI source-page viewer with selectable extracted text and copyable citation.
- Authoritative external discovery shortcuts.

## Next
- OCR for scanned/image-only PDFs.
- Source-backed authority assumption profiles for calculators.
- SirisHydro answer composition over citation-bearing evidence.
- Optional semantic embeddings after deterministic retrieval/provenance is established.

The licensed PDF remains authoritative throughout; extracted text and future model output are derived aids.
